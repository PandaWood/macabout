macabout

About This Mac, for Linux

macabout shows your Linux system-info the way macOS does... specifically catering for re-purposed Macs.

Install
curl -sSL https://pandawood.github.io/macabout/install.sh | bash

The installer works on Arch-based distros as well as Debian/Ubuntu. It checks which you're running and installs the package.

Run as your normal user, without sudo. macabout will ask for a password when it needs root.

Debian family
Debian, Ubuntu, Mint, Zorin and their relatives. Downloads the latest .deb and installs it along with its dependencies.
Arch family
Arch, CachyOS, Manjaro, EndeavourOS and their relatives. Installs base-devel if it's missing, then builds and installs the package from the latest PKGBUILD with makepkg.
Other distros
Fedora, openSUSE and the rest aren't packaged yet. macabout still runs on them: run it from source.
What it reads
Distro and version/etc/os-release
Machine modeldmidecode
Processor/proc/cpuinfo
Memory/proc/meminfo, and dmidecode for speed and type
Graphicslspci, matched against a bundled table of cards
Serial numberdmidecode
Permissions
dmidecode needs root. Both packages add a sudoers rule for it, so macabout opens without a password prompt.
Source
PandaWood/macabout on GitHub. To install by hand, the .deb and PKGBUILD are attached to the latest release.
